A tiny program with one job: it writes a single one-line joke about
pairing with AI coding agents into `/output/entry.txt`. The rehearsal
went perfectly, the live demo died in four seconds, and the agent's
incident report blamed the only input nobody had tested — the audience.

## Run it

```sh
python3 main.py
```

That writes the joke to `/output/entry.txt` (set `MAKEFUN_OUTPUT_DIR` to write somewhere else). The program uses only the Python standard library.
